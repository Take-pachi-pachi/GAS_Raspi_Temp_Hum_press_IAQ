# SensorData2SpreadSheets (Environmental Data Logger)

Google Apps Script (GAS) を利用して、温湿度センサや気圧センサなどの環境測定デバイスから、Web API（GETリクエスト）経由でGoogleスプレッドシートに測定データを自動追記（ロギング）するためのスクリプトです。

Raspberry Pi、ESP32、M5StackなどのIoTデバイスから、各種センサーデータ（温度・湿度・気圧・IAQなど）を収集し、スプレッドシートへリアルタイムに蓄積するための「橋渡し（Bridge）」として機能します。

## 🚀 主な機能

* **Web API化**: 外部IoTデバイスからHTTP GETリクエスト経由でデータを受け取り、スプレッドシートへ自動書き込みします。
* **動的なシート指定**: クエリパラメータ `p1` によって、書き込み先シート（例: `Test` や `LivingRoom`）を動的に切り替えることができます。
* **可変長データ入力（データ数無制限）**: `p2` 以降のパラメータ（`p2`, `p3`, `p4` ... `pN`）を自動検出するため、送信データ項目数の制限や固定枠がありません。
* **GAS側での自動日時入力**: リクエスト受信時にGAS側で日本時間の現在日時（`yyyy-MM-dd HH:mm`）を取得して1列目に記録するため、デバイス側にRTC（時計機能）や時刻同期処理が不要です。
* **堅牢なエラーハンドリング & JSONレスポンス**: 処理結果を `{"value": "ok"}` や `{"value": "sheet_not_found"}` などの明確なJSON形式で一貫して返却します。

## 🛠️ クイックセットアップ（3ステップ）

### 1. スプレッドシートの準備
1. スプレッドシートを新規作成し、URLから **スプレッドシートID**（`/d/` と `/edit` の間の文字列）をコピーします。
2. 書き込み先のシートタブ（例: `Test`）を作成し、必要に応じて1行目にヘッダーを配置します。

### 2. GASの配置とプロパティ設定
1. **[拡張機能] > [Apps Script]** を開き、プロジェクト内のコード（`Code.gs`）の内容を貼り付けて保存します。
2. 左メニューの **[プロジェクトの設定（歯車アイコン）]** ➔ **[スクリプトプロパティを追加]** で、以下を設定します。
   * **プロパティ**: `Spread_ID`
   * **値**: コピーしたスプレッドシートID

### 3. Webアプリとしてデプロイ
1. 右上の **[デプロイ] > [新しいデプロイ]** をクリックします。
2. 種類で **[Webアプリ]** を選択し、以下を設定してデプロイします。
   * **次のユーザーとして実行**: `自分`
   * **アクセスできるユーザー**: `全員`
3. 発行された **ウェブアプリのURL** をコピーします。

## 📝 API 仕様

### 基本情報

* **メソッド:** `GET`
* **URL:** `https://script.google.com/macros/s/XXXXX/exec` （デプロイ時に発行されたURL）

### クエリパラメータ

| パラメータ | 必須 | 概要 | 送信データの例 | 対応する列 |
| :--- | :---: | :--- | :--- | :--- |
| `p1` | ✅ | 書き込み対象の**シート名** | `Test`, `Living` | **B列: シート名** |
| `p2` | 任意 | 送信データ（項目1） | `2026-09-26_10:15` | **C列: データ1** |
| `p3` | 任意 | 送信データ（項目2: 温度など） | `26.58` | **D列: データ2** |
| `p4` | 任意 | 送信データ（項目3: 湿度など） | `54.20` | **E列: データ4** |
| `p5`〜`pN` | 任意 | 送信データ（項目4以降） | `1013.75`, `542062` ... | **F列以降: 各データ** |

> ℹ️ **注:** 1列目（A列）の日時データはGAS側で自動入力されます。

### リクエスト例

```bash
curl -L "[https://script.google.com/macros/s/XXXXX/exec?p1=Test&p2=2026-09-26_10:15&p3=26.58&p4=54.20&p5=1013.75&p6=&p7=&p8=&p9=&p10=542062&p11=0.00&p12=1&p13=0](https://script.google.com/macros/s/XXXXX/exec?p1=Test&p2=2026-09-26_10:15&p3=26.58&p4=54.20&p5=1013.75&p6=&p7=&p8=&p9=&p10=542062&p11=0.00&p12=1&p13=0)"
```

> ⚠️ **注意:** Curlやマイコン等からリクエストを送る際は、リダイレクト処理（`-L` オプション等）を有効にしてください。GASのWebアプリは処理時に一時的なリダイレクト（HTTP 302）が発生します。

#### スプレッドシートへの書き込み列構成

| A列（日時） | B列（シート名 / p1） | C列（p2） | D列（p3） | E列（p4） | F列（p5） | ... | N列（pN） |
| :--- | :--- | :--- | :--- | :--- | :--- | :--- | :--- |
| **2026-09-26 10:15** | Test | 2026-09-26_10:15 | 26.58 | 54.20 | 1013.75 | ... | 0 |

## ↩️ レスポンス

レスポンスはすべて `application/json` 形式で返却されます。

### 成功時 (Status 200)

```json
{
  "value": "ok"
}
```

### エラー時 (Status 200)

| 返却値 (`value`) | 原因と対処法 |
| :--- | :--- |
| `undefined` | クエリパラメータが何も付与されていません。 |
| `missing_sheet_name` | `p1` パラメータ（シート名）が指定されていません。 |
| `sheet_not_found` | `p1` で指定された名前のシートタブがスプレッドシート内に存在しません。 |
| `error: [メッセージ]` | その他の例外エラーが発生しました。 |
