# GAS Spreadsheet Web API (Environmental Data Logger)

Google Apps Script (GAS) を利用して、温湿度センサや気圧センサなどの環境測定デバイスから、Web API（GETリクエスト）経由でGoogleスプレッドシートに測定データを自動追記（ロギング）するためのスクリプトです。

M5Stack、ESP32、Raspberry PiなどのIoTデバイスからお部屋（Home-LDK, Home-2Fなど）の各種センサー環境データを収集・蓄積する簡易データベース（DB）化、REST APIの構築に最適です。

## 🚀 主な機能

* **Web API化**: 外部IoTデバイス等からHTTP GETリクエスト経由で環境データを受け取り、スプレッドシートへ自動書き込みします。
* **部屋・エリア別の動的なシート選択**: クエリパラメータ（`p7`）によって、書き込み先シート（例: `Home-LDK` や `Home-2F`）を動的に切り替えることができます。
* **日時データのスペース復元機能**: `p1` パラメータに含まれるアンダースコア（`_`）を自動的に半角スペースへ置換して保存します。これによって、URL送信時に壊れやすい「日付と時間の間のスペース」（例: `2024-10-09_9:15` ➔ `2024-10-09 9:15`）をスプレッドシート側できれいに復元して記録できます。
* **JSONレスポンス**: 処理結果を `{"value": "ok"}` または `{"value": "undefined"}` のJSON形式で一貫して返却します。

## 📝 API 仕様

### 基本情報

* **メソッド:** `GET`
* **URL:** `https://script.google.com/macros/s/XXXXX/exec` （デプロイ時に発行されたURL）

### クエリパラメータ

| パラメータ | 必須 | 概要 | 送信データの例 | 対応する列 |
| ----- | ----- | ----- | ----- | ----- |
| `p7` | ✅ | 書き込み対象の**シート名** | `Home-LDK`, `Home-2F` | *(書き込み先シートタブ)* |
| `p1` | ✅ | 日時データ | `2024-10-09_9:15` | **A列: 日時**（`_` は自動的に半角スペースに復元） |
| `p2` | ✅ | 温度データ | `23.47` | **B列: 温度 [℃]** |
| `p3` | ✅ | 湿度データ | `63.29` | **C列: 湿度 [%]** |
| `p4` | ✅ | 気圧データ | `1010.03` | **D列: 気圧 [hPa]** |
| `p5` | ✅ | IAQ（空気質）データ | *(空文字または数値)* | **E列: IAQ** |
| `p6` | ✅ | DI（不快指数）データ | `68.6` | **F列: DI** |

### リクエスト例

```bash
curl -L "https://script.google.com/macros/s/XXXXX/exec?p7=Home-LDK&p1=2024-10-09_9:15&p2=23.47&p3=63.29&p4=1010.03&p5=&p6=68.6"

> ⚠️ **注意:** Curlや外部プログラムからリクエストを送る際は、リダイレクト（`-L` オプション）を有効にしてください。GASのWebアプリはGoogleサーバー内で一時的にリダイレクトされる仕様になっています。

#### スプレッドシートへの書き込み結果

リクエストを受けると、指定したシート（例: `Home-LDK`）の最終行に以下のように一行追記されます。

| 日時 (A) | 温度 [℃] (B) | 湿度 [%] (C) | 気圧 [hPa] (D) | IAQ (E) | DI (F) |
| ----- | ----- | ----- | ----- | ----- | ----- |
| **2024-10-09 9:15** | 23.47 | 63.29 | 1010.03 |  | 68.6 |

## ↩️ レスポンス

レスポンスはすべて `application/json` 形式で返却されます。

### 成功時 (Status 200)

データが正常にスプレッドシートへ書き込まれた場合。

```json
{
  "value": "ok"
}

### エラー時 (Status 200)

パラメータが受け取れなかった、または不足している場合。

```json
{
  "value": "undefined"
}

## 💡 応用・カスタマイズのヒント

* **日時をGAS側で自動入力にする場合**:
  現在、日時（`p1`）をデバイス側から送信していますが、デバイスにRTC（時計機能）がない場合などは、GAS側で `new Date()` を使い自動で実行日時を書き込ませるようにコードを改造することも可能です。

* **書き込む列数の変更**:
  デバイスがさらに新しいデータ（例：CO2濃度、照度など）を測定できるようになった場合は、`var array = [...]` 部分にパラメータを増やすことで、簡単に記録列を拡張できます。
